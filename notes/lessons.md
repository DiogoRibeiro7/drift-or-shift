# Lessons Learned

1. **Offset correction matches the oracle under pure label shift.** The synthetic (Exp1) and breast-cancer (Exp5) tables show `risk_offset` falling to ~0.008 and ~0.009 for `pi_test=0.01`, nearly matching the oracle risks listed in the same tables (`results/.../tables/exp1_label_shift_synth.csv` and `results/.../tables/exp5_realdata_breast_cancer.csv`). This reinforces the paper’s premise that a single logit offset suffices when only prevalence changes.
2. **AUC is stable while PR-AUC climbs with prevalence.** Exp2’s aggregated data (`results/exp2_auc_pr_invariance/.../tables/...`) keeps ROC AUC within ~0.94–0.96 but lifts PR AUC from ~0.35 to ~0.94 as `pi_test` grows, so any discussion of classifier quality under imbalance should favor ROC AUC for ranking and PR AUC for calibrated performance.
3. **Class weighting shrinks the effective sample faster than training size suggests.** Exp3’s ESS fraction drops from 1.0 to 0.23 as `alpha` increases from 1 to 50 (`results/exp3_ess_vs_weight/...`), hinting that aggressive weighting may hurt more than help because the reweighted data effectively behaves as fewer observations.
4. **Concept drift breaks offset correction but retraining recovers.** The concept-drift table (`results/exp4_concept_drift/.../tables/exp4_concept_drift.csv`) reports identical `risk_none` and `risk_offset` yet a lower `risk_retrain`, so when class-conditionals move, retraining on the new distribution is mandatory.
5. **Solver warnings on the real dataset signal a scaling/iteration gap.** The LBFGS convergence warnings during Exp5 suggest maintaining scaled features or increasing `max_iter` when rerunning on real data; otherwise offset correction benefits might be masked by solver instability.
